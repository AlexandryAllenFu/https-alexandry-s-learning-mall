## 2. 学习深度、重要性与判级

高=通常高中已接触；衔=大学要求下重新组织或高中覆盖不一；新=按本项目作为大学新内容。这里只是内容分类，不代表Alexandry已会；高中内容先短测，失败则补，成功不重复长讲。

P0=优先打通的基础或综合题关键；P1=覆盖必需；P2=理解与证明思路后置。这是教学优先级，不是学校公布的题目权重。D1=能说清含义、条件与推理主线；D2=能独立完成标准题并解释条件；D3=能完成陌生变式、解释方法选择并检查特殊点。

## 6. 英文题意→概念→动作

| 英文信号 | 你要理解什么 | 首先做什么 |
|---|---|---|
| state/find the natural domain | 使原表达式有意义的全部实数输入 | 根号、分母、对数、反三角限制分别列出，取交集 |
| one-to-one / inverse / principal value | 一一对应、反函数、指定主值范围 | 查定义域与值域，区分inverse与reciprocal |
| evaluate the limit / does not exist | 求趋近行为，不是单纯代点 | 试代判断类型，必要时左右拆开 |
| removable discontinuity / define to be continuous | 能否补一个点接上 | 查有限两侧极限，再与点值比较 |
| show that ... has at least one solution | 证明存在，不一定求出根 | 构造连续函数，找异号或端点覆盖目标值 |
| using the definition of derivative | 必须用差商极限 | 写出原函数在该点的差商，不能仅套公式 |
| differentiable everywhere | 所有点可导，重点在拼接点 | 先查连续，再查两侧导数，不只分段求导 |
| tangent line / horizontal tangent | 点斜式 / 有限导数为0 | 检查点在曲线上与导数存在，再求斜率 |
| express in terms of F | 用F、F′表示 | 不需要猜F的公式，识别复合与链式 |
| at what rate / when / with respect to time | 某瞬间的时间变化率 | 分清变量值与导数、正负方向和单位 |
